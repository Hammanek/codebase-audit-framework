# Universal Rules (TIER 0)

## 1. Clean Code & Pragmatické inženýrství
- **Kód:** Stručný, přímý, bez over-engineeringu. Samovysvětlující názvy proměnných a funkcí.
- **Komentáře:** Zachovávej existující komentáře a docstringy, nepřidávej zbytečný komentářový šum popisující zjevné věci.
- **Testování:** Testovací pyramida (Unit > Integrační > E2E) + AAA Pattern (Arrange-Act-Assert).
- **Bezpečnost:** Zero-Trust, Fail-Secure, Least Privilege, ochrana tajemství.

## 2. Komunikační standardy
- Reaguj v jazyce uživatele (čeština).
- Kód, proměnné a technické komentáře zůstávají v angličtině.
- Odkazy na soubory vždy formátuj jako klikatelné odkazy ve standardu Markdown (`[file.py](file:///path/to/file#L10-L20)`).
