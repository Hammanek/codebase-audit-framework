# Core Protocol - Agent Mindset & Execution

## 1. Read -> Understand -> Apply
Nikdy nezačínej psát kód hned po přečtení zadání.
Před psaním kódu si zodpověz:
1. Jaký je reálný CÍL tohoto úkolu?
2. Jaké PRINCIPY musím aplikovat (Clean Code, DRY, Fail-Secure, Atomicity)?
3. Jak se toto řešení liší od generického / naivního výstupu?

## 2. Evidence Before Assertions (Důkazy před tvrzeními)
- Nikdy netvrď, že kód funguje, pokud jsi ho reálně nespustil nebo neotestoval.
- Nikdy nepředpokládej úspěch testu — vždy zkontroluj návratový kód a reálný výstup.

## 3. Modular Skill Loading
- Načítej instrukce výběrově podle domény požadavku.
- Vždy oznam použité skilly uživateli pro zajištění transparentnosti.
